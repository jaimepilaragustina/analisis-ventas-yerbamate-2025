# analisis-ventas-yerbamate-2025
Análisis de ventas de yerba mate durante 2025 utilizando Microsoft Excel y Power Query
Descripción del proyecto

Este proyecto consiste en un análisis de ventas de yerba mate correspondiente al período enero-diciembre de 2025.

El objetivo fue integrar, transformar y analizar datos mensuales para identificar tendencias de facturación, comportamiento de ventas y desempeño de marcas y productos.

El trabajo se realizó utilizando Microsoft Excel y Power Query, con el desarrollo de tablas dinámicas, indicadores clave de rendimiento (KPIs), gráficos y un dashboard interactivo.
Herramientas utilizadas

    Microsoft Excel: organización, análisis y visualización de datos.

    Power Query: importación, integración y transformación de datos.

    Pivot Tables: resumen y análisis de información comercial.

    Pivot Charts: visualización de resultados.

    Slicers: filtros interactivos por marca y mes.

Proceso de trabajo


    Integración de 12 archivos correspondientes a los meses de enero a diciembre de 2025 mediante Power Query.

    Consolidación de una base anual de 120 registros, correspondientes a 10 productos durante 12 meses.

    Limpieza, transformación y organización de los datos.

    Cálculo de indicadores comerciales.

    Análisis de facturación mensual, facturación por marca, unidades vendidas y facturación por variedad.

    Desarrollo de un dashboard para visualizar los principales resultados.

Dashboard

El dashboard presenta los principales indicadores y visualizaciones del análisis.


Incluye:

    Facturación total.

    Unidades vendidas.

    Precio promedio ponderado.

    Marca líder.

    Facturación por marca.

    Unidades vendidas por marca.

    Evolución mensual de la facturación.

    Facturación por variedad.

    Filtros interactivos por marca y mes.

Principales resultados

    Facturación total: $6.078.097.

    Unidades vendidas: 2.343.

    Precio promedio ponderado: $2.594.

    Marca líder en facturación: Rosamonte, con $2.126.252.

    Marca líder en unidades vendidas: Rosamonte, con 827 unidades.

    Producto con mayor volumen de ventas: Rosamonte Tradicional, con 338 unidades.

    Variedad con mayor facturación individual: Cósmico Tradicional, con $1.487.732.

Evolución de ventas

La facturación mensual mostró una tendencia creciente durante el período analizado, pasando de $196.512 en enero a $959.585 en diciembre.

El mayor incremento porcentual mensual se registró entre abril y mayo, con un crecimiento del 47,19%.

Los resultados monetarios reflejan la evolución de la facturación y no necesariamente un crecimiento equivalente en el volumen de unidades vendidas.
Conclusiones

El análisis permitió identificar a Rosamonte como la marca con mayor participación en facturación y volumen de ventas.

A nivel individual, Rosamonte Tradicional fue el producto más vendido en unidades, mientras que Cósmico Tradicional registró la mayor facturación entre las variedades analizadas.

La utilización de Power Query permitió integrar y transformar información proveniente de múltiples archivos, facilitando la construcción de una base consolidada para su posterior análisis.

Este proyecto permitió aplicar herramientas de Excel y Power Query en un caso práctico de análisis de datos comerciales.

Proyecto desarrollado con fines de aprendizaje y portfolio profesional.
